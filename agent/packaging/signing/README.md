# Package signing

The `.deb` and `.rpm` are GPG-signed so an operator's own package manager can
verify what it installs. This directory will hold only the PUBLIC key. The
pattern is that of an earlier project of the author's, reviewed and adapted.

**The private key never enters this repository and never touches any server.**
It lives on the signer's machine and in the password manager. Signing happens
locally at build time; servers only ever host already-signed files.

## The key

- File: `whichports-signing-public.asc` (ASCII-armored public key, committed here).
- Fingerprint: `3EED C9C6 E494 0A81 5D42  CE43 680A 9082 6E2C 982D`
- Identity: `Whichports <hello@whichports.com>`, RSA 4096, created 2026-08-13,
  no expiry. Generated by the owner; the private half lives on his machine and in
  the password manager only.

## How it was generated (for the record)

```sh
gpg --full-generate-key
#   kind: RSA and RSA, 4096 bits, does not expire
#   name: whichports package signing
#   email: hello@whichports.com
```

Then export both halves:

```sh
# The public half, committed HERE as whichports-signing-public.asc:
gpg --armor --export hello@whichports.com > whichports-signing-public.asc

# The private half, for the password manager and the build command, never git:
gpg --armor --export-secret-keys hello@whichports.com > /somewhere/private/whichports-signing-private.asc
```

Commit the public `.asc` into this directory and record the fingerprint in
this file. After that, releases are:

```sh
SIGNING_KEY_FILE=/path/to/whichports-signing-private.asc \
NFPM_PASSPHRASE='the passphrase' \
make package-signed
```

## Verifying a package (operator)

```sh
# rpm family
sudo rpm --import whichports-signing-public.asc
rpm --checksig -v whichports-agent-*.rpm

# deb family: apt trust comes from signed repository metadata once the hosted
# repo exists; the repo location is an open decision on the board.
```
